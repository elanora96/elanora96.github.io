# Using Dislocker to mount Bitlocker volumes

I was having trouble finding documentation for `dislocker`

A [blogpost by Linux Uprising](https://www.linuxuprising.com/2019/04/how-to-mount-bitlocker-encrypted.html) was helpful getting started for me, I'm just going to write some notes for myself on it here.

I installed [`dislocker-patched`](https://aur.archlinux.org/packages/dislocker-patched) from the AUR.

Then similar to the blogpost I made two folders, though I decided to do this in `/mnt`

Also note the system I was on uses `doas` instead of `sudo`

```zsh
doas mkdir -p /mnt/bitlocker
doas mkdir -p /mnt/bitlockermount
```

I then used `lsblk` to identify the partition I wanted to unlock. I could tell from the size easily, but if you need more info `lsblk --fs` will print file system data.

In my case it was `/dev/nvme0n1p3` as shown here:

```zsh
❯ lsblk --fs

     ext4   1.0             170729b1-150c-4006-8521-b2e00c104be0    1.1T    27% /
```

Finally, the reason I'm writing this note. Here is how you unlock a partition with `dislocker`

```zsh
doas dislocker /dev/nvme0n1p3 -- /mnt/bitlocker

doas mount -o loop /mnt/bitlocker/dislocker-file /mnt/bitlockermount
```

\*Do note that unlike the blogpost, I have omitted the -u\<password> param. Omitting it brought up a prompt that worked while the param always failed for me.
